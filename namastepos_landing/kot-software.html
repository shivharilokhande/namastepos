FAQ

Questions, answered

What is a KOT?
KOT stands for kitchen order ticket. It is the slip the kitchen cooks from: the table or token number, the items, the quantities and any instruction such as no onion or extra spicy. It is not the customer's bill. The bill carries prices and tax, the KOT carries only what the kitchen needs to cook.
Do I need a kitchen printer, or will a screen do?
Either works. A Bluetooth or network thermal printer in the kitchen prints a paper ticket the cook can spike. A kitchen display shows live tickets on a phone, tablet or old monitor, with no paper and no consumables. Many outlets run both, a printer for the hot section and a screen for the pass.
Do KOTs work when the internet is down?
Yes. The order is written to the phone first, so the KOT still goes out to a Bluetooth or local network printer with no internet at all. The kitchen display keeps working on the same local network. When the connection returns the orders replay to the server once, each with the ID it was created with, so nothing is billed twice.
