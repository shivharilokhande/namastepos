## 4. MANDATORY clearance checklist (run on your chosen name BEFORE committing)

You said "I don't want any trouble." Then **all** of these must be green before you incorporate, buy the domain, or print a single business card. Total cost: ~₹8,000-15,000. Total time: 5-10 business days.

### 4.1. Indian Trademark Database search (free, do yourself)
1. Go to **https://search.ipindia.gov.in/TMRPublicSearch/** ("Public Search" page)
2. Search "Wordmark" → type your chosen name
3. Run the search in each relevant class:
   - **Class 9** — computer software (downloadable, recorded)
   - **Class 42** — SaaS, software-as-a-service
   - **Class 35** — business management, advertising, retail
   - Also do a wider search across "All Classes" to catch close-sounding marks
4. If you see ANY active mark with the same or similar wordmark in Classes 9/35/42 → pick a different name
5. If results show only "Abandoned" or "Refused" marks → likely safe but still confirm with lawyer
6. Save a screenshot of the empty search result as evidence of due diligence

### 4.2. MCA company-name availability (free, do yourself)
1. Go to **https://www.mca.gov.in/** → MCA Services → Company Forms Download → "Check Company Name"
2. Search variants: "<Name>", "<Name> Technologies", "<Name> Software", "<Name> Solutions"
3. If a Pvt Ltd / LLP exists with same or close name → MCA will reject your incorporation application later. Pick different name.

### 4.3. Domain availability (₹0 to verify, ₹500-2000 to buy)
1. Check on **whois.com** or **registry.in**:
   - `<name>.in` — your primary
   - `<name>.com` — global protection
   - `<name>.app` — modern fallback
   - `<name>.tech` — alternative
2. **Critical:** if .com is owned by a major company in any industry, they may pursue you under cyber-squatting laws even if you only use .in. Avoid this.
3. Buy the `.in` immediately (before you publish the name anywhere). Hostinger India = ~₹800/year.
4. If .com is available, **buy it too** — it's ~₹1000/yr and prevents future confusion.

### 4.4. Social handle availability (free)
1. Reserve handles on: **Instagram, Twitter/X, LinkedIn, Facebook, YouTube, Google My Business**
2. If `@yourname` is taken across most of these by an active brand → choose a different name. Confusion in customer mind = real-world conflict.

### 4.5. App store availability (free)
1. Search Google Play and Apple App Store for your chosen name
2. If an active app with the same name exists in **any** category → Apple/Google will reject your submission. Pick different name.
3. Especially check business / productivity / food categories.

### 4.6. Lawyer-led trademark opinion (₹5,000-10,000, MANDATORY)
1. Hire a trademark lawyer in India (any major city, look for IP-focused firms)
2. Ask them to issue a **written clearance opinion** for your final name in Classes 9, 35, 42, and 43 (restaurant services for safety)
3. This document is your shield if anyone challenges you later — proves you did due diligence
4. Cost: typically ₹5,000-10,000 for the search and written opinion

### 4.7. File the trademark application (₹4,500 govt fee per class + ~₹3,000 lawyer fee = ~₹13,000-20,000)
1. Once cleared, **file the TM application immediately** before public launch
2. File in Classes 9 + 42 at minimum (software + SaaS). Add Class 35 if you offer marketing/analytics features. Add Class 43 only if you ever expand into running restaurants yourself.
3. Filing puts you in first-use position. Even if the mark isn't granted for 18-24 months, the filing date is what matters in disputes.
4. Use a TM agent / lawyer for filing — DIY filing often has technical defects.

### 4.8. Check FSSAI conflicts (free, just one search)
Since you're in food-adjacent SaaS:
1. Search **https://foscos.fssai.gov.in/** for any registered food business with the same name
2. Not a direct legal block (different licensing regime) but flags confusion risk
